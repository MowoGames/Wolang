# C++ in this repository

- Chromium style: 2 spaces, 80 columns, `PascalCase` types and functions, `snake_case` variables
  and files, `trailing_underscore_` class members (plain structs: none), `kPascalCase` constants and
  enum values, out-params by pointer, guards `WOLANG_<PATH>_H_`, include order: own header, C, C++, project.
- `-fno-exceptions -fno-rtti`: no throw/try, no dynamic_cast/typeid (use tag fields), no throwing std APIs
  (`std::filesystem` error_code overloads, `std::from_chars`).
- Generic-word layers get nested namespaces (`wolang::ir`) - a duplicate `wolang::Module` is an ODR bug.
- Files are **not** clang-format clean: never format a whole file; match the surrounding code.
- `include/wolang/base/unicode_tables.inc` is generated by `tools/gen/gen_unicode_tables.py`.
- Headers in `include/wolang/<layer>/` mirror `src/<layer>/`; `tools/package/check_includes.py` checks
  every file includes what it uses (`wl docs`).
- Tests: `tests/unit/<layer>/<name>_unittest.cc`, `WOLANG_TEST(Suite, Name)`, `WOLANG_EXPECT*` continues,
  `WOLANG_ASSERT*` returns. Diagnostics asserted by code. Test files and suites are globbed - nothing to register.
- Giant files (grep, then read ranges): src/ir/lower.cc 285 KB, src/sema/type_check.cc 145 KB,
  tools/wolang/main.cc 115 KB, src/codegen/{arm64,x64}/emitter.cc ~110 KB.
