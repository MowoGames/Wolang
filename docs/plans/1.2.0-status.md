# 1.2.0: where it stands

Written 2026-11-01 on branch `feature/1.2.0`, cut from `alpha`. The plan is
[1.2.0.md](1.2.0.md). The code is complete and passes everything that can be
run on Windows x86-64; it has not been pushed, so no other platform has seen
it. The engine's wish list is in [engine-needs.md](engine-needs.md).

## Checked, on Windows x86-64 (`WL_PRESET=windows`)

- `wl ci`: all green. 963 unit tests, 0 failed.
- `wl lib`: std 170, http 48, game 7, core 2, gfx 10, image 40, math 35, db 4,
  tls 1, and `wl wo test tools/selfhost/lexer` 7. 0 failed.
- `wl docs`: 76 programs, 0 broken. `wl fmt`, includes and version: ok.
- `wl fuzz 200` on seeds 16586, 4242 and 11040: 0 disagreed.
- The `asan` preset builds (it needed the CRT defines, the release CRT and the
  8 MB stack). Every unit suite except `AotTest`, and the std, core, db,
  game, image, math and http packages, run clean under it: no leak, double
  free or use after free.
- The tests added with `ec7c62f` and `de90f56` fail without their fix and pass
  with it (`KeepsACastThatCanTrapWhenItsResultIsUnused`,
  `LeavesATrappingCastOnTheBranchThatRunsIt`,
  `FreeReadsTheDataOfASliceAsAPointer`,
  `ParallelForTakesItsThreadCountAtTheRuntimesWidth`); the twin
  `DropsAnUnusedCastThatCannotTrap` passes either way, as it should.

## Open risks and known gaps

- Engine item 6 (host-held objects migrating on reload) is a fallback: a
  reload that would change a class a host holds an object of is refused with
  a note (D255). Item 22's `if const` on an `AActor?` was fixed by reading the
  boxing code; it has an embedding test but has not run against a real
  engine handle.
- A name that is not imported, used as an error in a `match` arm, reports
  `E0201`, not an unknown-name error.
- A function held in a variable and passed to a `@Thread` parameter is not
  judged by `E0147` (D252).
- `"{MakeText()}"` leaks its temporary. A payload error held in a `const`
  before it reaches a `T!` leaks its box.
- A closure that stores itself in `self` is a cycle; a kept closure made
  in an `arena` block must not outlive it (D240).
- A weak host slot with a token points at a small cell the runtime allocates
  (D254); a weak host field set by any path other than the constructor store,
  `WritePlace` or `EmitFileInit` would break that. `object_set` and the
  reload field-carry were checked by reading only.
- The generated binding glue still registers classes without a token.
- The read-only slice (D251) was migrated across the library by script. If it
  proves unstable on another platform, its commits are the last series on the
  branch (`858f3bc`, `537dfd0`, `cabb869`, `bdb2b9e` and the fixes after them)
  and can be reverted as a unit.
- `uses unsafe` callers of `AtomicAdd`, `socket.Read` and `gfx.TextFromC` now
  pay for `unsafe`; library users with their own wrappers may see `E0704`.

## Cut from 1.2.0, to 1.3.0

`font`, `audio`, `gpu`, an immediate-mode `ui` and `app`. They bind devices and
platform services (an audio device, a GPU API, a window system) that could
not be run on the machine this release was built on, and code written blind
for them would have shipped untested. The engine's suggested additions
(replication, a debug protocol, an execution budget, coroutines tied to the
game clock, serialization, a versioned binding ABI, sandboxing, AOT without
a system `cc`, published benchmarks) are deferred too: each needs a decision
first. Engine items 15 and 16 are in; the generator's output was checked
against its own tests, not against the engine's headers.

## Traps met

- On Windows `wl` defaults to the `debug` preset, which fails on CRT
  deprecation warnings. Use `WL_PRESET=windows`.
- The `asan` preset needs `C:\Program Files\LLVM\lib\clang\<n>\lib\windows`
  on `PATH` for `clang_rt.asan_dynamic-x86_64.dll`.
- Run one build or test process at a time. Overlapping runs clobber each other.
- `wl wo new` writes backslashes into the manifest's std path on Windows.
- A hook blocks Bash commands that name `embed.cc` or `decisions.md`; stage
  with `git add -u` or a directory, and append decisions with a script.
- `wolang fmt --write <files>` rewrites files in place; without `--write` it
  only reports.
- Do not commit to `alpha`. No `Co-Authored-By` or "Generated with Claude
  Code" line in commits.
