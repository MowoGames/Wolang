# 1.2.0

The breaking language decisions land together, the known gaps close, and
`std` gets what a compiler needs. Self-hosting itself starts after this
release (D250, [self-hosting.md](self-hosting.md)).

Every step ships its test, `wl fuzz 200` when it touches lowering, a back end,
the interpreter or the runtime, and the docs and STATUS.md that agree with it.

## A. Language breaks, in this order

1. `int` is 64 bits (D238): D2 flips the default, D3 removes the 32-bit masks
   and widens the fuzzer. D1's guard is in.
2. `Self` and operator abilities (D239).
3. Errors carry data; offered functions state their sets (D235).
4. `unsafe fun` (D236).
5. `@Hot` checks allocation (D237).
6. Escaping closures with `keep` (D240, F1-F2; F0 is in).

## B. Known gaps

- `var a: s8 = -128` traps in every tier.
- `"{t}"` of an owned `Text` in a loop is `E0122` on the second iteration.
- Qualified names in patterns, as intrinsic callees and as assignment targets (D246).
- `E0147` across modules, method calls and function values.
- A read-only slice, so `Bytes` need not be `unsafe` (D233).
- A deadline on the blocking `Serve`/`ServeWith` path.
- An AOT install names LLVM's component libraries in its CMake and embedding packages.
- Paths written but never run locally: Windows UDP and `gfx`, Cocoa, arm64
  emitter changes, `aot.cc`. CI is the gate.

## C. Libraries that need A

`math` first (vectors with operators; the only one self-hosting needs), then
`font`, `audio`, `gpu`, an immediate-mode `ui`, `app`. The last five move to
1.3.0 if the schedule slips.

## D. Groundwork for self-hosting (stage 0)

- Check `std` for what a compiler needs: a fast `Map`, arenas, text building,
  files, process.
- The IR reader (the printer is stable; a dump cannot be read back).
- A throwaway Wolang lexer for Wolang, to find the gaps early.

## E. What the engine needs (owner decision 2026-11-01: in 1.2.0)

[engine-needs.md](engine-needs.md) items 1-25 are part of this release. Each is
first reproduced against this repo (the list was written on the engine side), then
fixed with the test that fails without it, or closed as not a bug with the reason.

- Language: 20 (alias across packages), 21 (`extend` of a foreign class), 22 (`if const`
  on optionals, `?.` with a method call), 24 (false unused-import), 23 (`after` in
  `machine`, host clock hook), 2 (module-level `weak var`).
- Lifetime and safety: 9 (`alive` and address reuse), 10 (liveness hook), 3 (release on
  VM destroy), 19 (subclass and upcast of an `extern class`).
- Hot reload: 6 (migrate live objects), 7 (a failed reload keeps the old program).
- Embedding API: 1, 4, 17, 18, 25 (objects and structs across the boundary); 5, 8, 11,
  12 (writer, per-VM bindings, `need` for a single file, module-qualified names).
- Binding generator: 13, 14, 15, 16, wherever the generator lives.
- The engine's suggested additions need a decision each (D-number) before any code.
  Whatever has no decision by the end moves to 1.3.0 with the reason in STATUS.md.

## Release gate

`wl ci`, `wl fuzz 200`, `wl docs`, and CI green on every platform; then
STATUS.md, CHANGELOG.md and the wrap-up skill.
