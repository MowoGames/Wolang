# 1.3.0: where it stands

Written 2026-11-02 on branch `feature/1.3.0`, cut from `alpha` after 1.2.0
merged. The plan is [1.3.0.md](1.3.0.md); this file says what is done, what is
not, and what was not checked. The engine's wish list is in
[engine-needs.md](engine-needs.md).

## Done

Nine streams of work, merged into `feature/1.3.0` and then built and tested as
one tree:

| Area | What | Decisions |
|---|---|---|
| Compiler | text ownership, payload-box leak, `E0166`, `E0163`, annotated ability locals, `Text` fields of a class | D275, D289 |
| Language | `@Save` and `std.save`, `task fun` with `Tick`/`Wait`/`Event`, replication attributes, hot-reload migration | D266, D267, D268 |
| Embedding | tick budget, versioned bindings, sandbox, traps with place and stack, liveness token in the glue, per-VM tasks | D265, D269, D270, D271, D254 |
| Libraries | `font`, `ui`, `audio`, `gpu`, `app`; `std.arena`; faster `std` | D276, D277, D279, D280, D281, D284, D285 |
| Tools | a lexer and a parser for Wolang in Wolang, package fetch and lock in Wolang, `wl bench`, AOT without a system `cc` | D272, D273, D283, D286, D287, D288 |
| Docs | the site converter publishes 14 packages, `docs/api` regenerated, what's new, benchmarks | D210 |

Checked on Windows x86-64 with the LLVM AOT backend built in: 1032 unit tests,
the library tests (std 182, http 48, game 7, core 2, gfx 10, image 40, math 35,
font 52, ui 23, audio 30, gpu 15, app 16), the docs check, `wl fuzz 200` on seeds
16586 and 4242, and `wl ci`.

## Not checked

- Linux, macOS and Windows on ARM64. Nothing has been pushed to CI for them
  before the PR. The first read of CI on each is the first job of 1.3.1.
- The bundled-linker link with a musl sysroot (D272): the command is built and
  its shape is tested, `tools/package/make_sysroot.sh` and the release job have
  never run, and the glibc-target object has not been linked against musl.
- The OpenGL backend and its `wolang_gpu_*` shims (D280) against a real
  context. A hand run of `examples/app` is needed.
- The execution budget on arm64 (D265): a budgeted VM runs the interpreter
  there. Ticks differ slightly between tiers.
- Fuzz coverage for save and load, tasks and the new libraries.
- Worktree builds configure with no LLVM unless `-DWOLANG_LLVM_C_ROOT=` points
  at `build/llvm-sdk`; `AotTest` then passes without testing anything.

## Not done

- Ogg Vorbis decoding (D279). Headers are read; the audio is not.
- `Class()` with no arguments ignores field initializers and leaves
  class-typed fields null. It needs a language decision.
- Assigning to an owned `Text` variable does not give back the old value; a
  `??` that picks its right operand leaves it to nobody.
- `E0163` judges function-typed locals and parameters, not a call result or a
  field of function type.
- A closure that stores itself in `self` is a cycle (D240).
- The engine's remaining wishes that were not in B: none are open in the list
  of 25; the suggested additions are all answered above. What the real engine
  finds when it uses the new bindings is not yet known (the generator was
  checked against its own tests, not the engine's headers).

## Traps met

- A merge that keeps both sides of an append can leave a test or a fenced code
  block without its closing line. After one, build and run `wl docs`.
- Run one build or test process at a time in one build directory. A fresh git
  worktree has its own build directory and no LLVM (see above).
- Do not commit to `alpha`; no `Co-Authored-By` in commits.
