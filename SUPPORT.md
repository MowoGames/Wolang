# Support

Where to take what.

| You have | Where it goes |
|---|---|
| A question about using the language | [Discussions](https://github.com/MowoGames/Wolang/discussions), category Q&A |
| An idea, or a change to the language you want to talk through | [Discussions](https://github.com/MowoGames/Wolang/discussions), category Ideas |
| A program that does the wrong thing | A [bug issue](https://github.com/MowoGames/Wolang/issues/new?template=bug.yml) with the smallest program that shows it |
| Something the language or a library should be able to do | A [feature issue](https://github.com/MowoGames/Wolang/issues/new?template=feature.yml) |
| A vulnerability | Not an issue: see [SECURITY.md](SECURITY.md) |
| A conduct problem | <contact@mowogames.com>, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before asking, these answer most questions:

- [docs/tour.md](docs/tour.md) — the language in examples
- [docs/cookbook.md](docs/cookbook.md) — whole programs that do a thing
- [docs/stdlib.md](docs/stdlib.md) — the standard library, module by module
- [docs/diagnostics.md](docs/diagnostics.md) — what each error code means
- [STATUS.md](STATUS.md) — what is done and what is not yet

Until 1.0, the newest commit on `alpha` is the supported version. A
report against an older build will usually be answered with "does it
still happen on `alpha`?".
